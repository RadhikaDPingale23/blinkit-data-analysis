# 🛍️ Blinkit Data Analysis Dashboard

> An interactive Power BI dashboard designed to analyze sales performance, customer behavior, and outlet operations using Blinkit sales data.

---

## ✨ About the Project

This project focuses on analyzing Blinkit's sales dataset to uncover valuable business insights through data visualization and KPI tracking. The dashboard provides a comprehensive view of sales trends, product performance, outlet efficiency, and customer satisfaction.

---

## 🎯 Project Objectives

✔ Analyze overall sales performance

✔ Identify top-performing product categories

✔ Evaluate outlet performance across different locations

✔ Understand customer satisfaction through ratings

✔ Generate meaningful business insights using data visualization

---

## 📈 Key Performance Indicators (KPIs)

| Metric | Description |
|---------|------------|
| 💰 Total Sales | Overall revenue generated |
| 📊 Average Sales | Average revenue per transaction |
| 📦 Number of Items Sold | Total items sold |
| ⭐ Average Rating | Customer satisfaction score |

---

## 📊 Dashboard Analysis

### 🥗 Fat Content Analysis
Comparison of sales contribution between Low Fat and Regular products.

### 🛒 Item Type Analysis
Performance analysis of different product categories.

### 🏪 Outlet Analysis
Evaluation of outlet size, type, and location performance.

### 📅 Outlet Establishment Analysis
Analysis of sales trends based on outlet establishment year.
